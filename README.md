# Introduction to Coding Quantum Algorithms: A Tutorial Series Using Qiskit

## 🎯 Objetivo do Software / Projeto
Este repositório contém uma série de tutoriais práticos focados em introduzir os conceitos de computação quântica e algoritmos quânticos utilizando o framework **Qiskit** da IBM. O objetivo é fornecer uma base sólida desde a criação do primeiro estado quântico até simulações de vetores de estado e superposição.

## 🏗️ Estrutura do Código e Tutoriais
O material é estruturado em lições interativas no formato Jupyter Notebook. 

A estrutura principal de arquivos inclui:
*   **Lição 1 (Lesson-1):**
    *   `Creating_Our_fist_Quantum_State.ipynb`: Criação e manipulação do primeiro estado quântico.
    *   `Lesson1-Intro_to_QuantumCircuits.ipynb`: Introdução a Circuitos Quânticos.
    *   `Lets_Bump_Up_the_Qubits.ipynb`: Trabalhando com múltiplos Qubits.
    *   `Our_First_Superposition_State.ipynb`: Implementação do primeiro estado de superposição.
    *   `State_vector_simulator.ipynb`: Uso do simulador de vetores de estado (Statevector).
    *   `biblioteca.py`: Scripts ou funções auxiliares em Python.
*   **Material de Apoio:**
    *   `Introduction_to_coding_quantum_algorithms.pdf`: Guia teórico/apresentação em PDF acompanhando a série.
    *   `teste_qiskit.ipynb`: Notebook para testes e validação da instalação do ambiente.

## 🛠️ Tecnologias e Ferramentas Utilizadas
*   **Linguagem Principal:** Python
*   **Framework Quântico:** Qiskit (IBM Quantum)
*   **Ambiente:** Jupyter Notebooks (`.ipynb`)
*   **Simuladores:** Qiskit Aer (Statevector Simulator)

## 🚀 Como Executar
1. Certifique-se de ter o Python (3.7+) e o Jupyter Notebook instalados em sua máquina.
2. Instale as dependências quânticas executando:
   ```bash
   pip install qiskit
   pip install qiskit-aer
   ```
3. Clone ou baixe este repositório.
4. Navegue até o diretório do projeto e inicie o Jupyter:
   ```bash
   jupyter notebook
   ```
5. Abra qualquer um dos arquivos `.ipynb` na pasta `Lesson-1` para iniciar o aprendizado interativo!
